## 🚀 About the Project

**SoundHaven** is a web3 music streaming dApp that empowers artists and listeners through decentralization and on-chain ownership. Inspired by my hobby, SoundHaven improves upon user experience, artist royalties, and tokenized access, built entirely on the **Solana blockchain**.

---

## 🎯 Features

- 🎵 Upload & stream music
- 🎫 On-chain artist and user registration using Anchor
- 💸 Tokenized royalty
- 🔐 Wallet-based login

---

## 🛠️ Tech Stack

### Smart Contracts
- 🦀 Rust + Anchor Framework
- 🧠 Solana Programs (CPI, PDAs, SPL)

### Infra
- 🧬 IPFS (via Web3.Storage)
- 🧪 Anchor Tests

## 🚦 Getting Started

### Prerequisites

- [Solana CLI](https://docs.solana.com/cli/install-solana-cli)
- [Anchor CLI](https://www.anchor-lang.com/docs/installation)
- [Rust](https://www.rust-lang.org/tools/install)
- [Node.js](https://nodejs.org/)

### 1. Clone the repo

```bash
git clone https://github.com/your-username/soundhaven.git
cd soundhaven
```

### 2. Build SoundHaven program

```bash
anchor build
```

### 3. Test SoundHaven program

```bash
anchor test
```
